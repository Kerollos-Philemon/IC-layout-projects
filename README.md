# IC Layout Projects — Cadence Virtuoso

A collection of physical design (layout) projects verified through 
DRC, LVS, and PEX in Cadence Virtuoso.

## Overview
This repository contains layout implementations demonstrating core 
physical design skills — floorplanning and routing for both digital standard cells and an analog building block.

## Projects

### Digital Standard Cells
- **Inverter**
- **NAND**
- **NOR**

### Analog
- **Differential Pair Layout** [Interdigitation matching technique ]

## Verification
Every design was taken through the full physical verification flow:
- **DRC (Design Rule Check)** Clean — no violations
- **LVS (Layout vs. Schematic)** Matched — layout confirmed against schematic
- **PEX (Parasitic Extraction)**
